# Elite FPL

> The analytical cockpit for serious Fantasy Premier League managers.
> React Native (Expo · New Architecture / Fabric) + TypeScript, dark-only,
> EN + AR (RTL) from day one.

This repository is the **production scaffold** for the Elite FPL product
described in [`elite-fpl-prd.md`](./elite-fpl-prd.md). The scaffold covers
architecture, design tokens, data models, navigation skeleton, state stores,
and stub screens for every PRD §5 screen. Feature logic lands on top of
this base in Phase 0–3.

## Quick start

```bash
# Install JS dependencies
npm install

# Generate native projects (required before first device run)
npx expo prebuild

# Run on iOS simulator (macOS only) or Android emulator
npm run ios
npm run android

# Type-check and lint
npm run typecheck
npm run lint
```

> **Do not run `expo prebuild` until `node_modules` is installed.**

## Design tokens

All visual constants live in [`src/theme/`](./src/theme) and match PRD §2:

| Token            | Value                                                        | File                                 |
| ---------------- | ------------------------------------------------------------ | ------------------------------------ |
| `bg.primary`     | `#0B1220`                                                    | [`colors.ts`](./src/theme/colors.ts) |
| `bg.surface`     | `#0F172A`                                                    | "                                    |
| `accent.primary` | `#10B981`                                                    | "                                    |
| `text.primary`   | `#F8FAFC`                                                    | "                                    |
| FDR 1–5          | 5 stops                                                      | `colors.fdr`                         |
| Spring presets   | pitchCard / captainPulse / tabSlide                          | [`motion.ts`](./src/theme/motion.ts) |
| Haptic map       | captainSet / transferConfirmed / chipPlayed / swipeToCompare | "                                    |

**Never** hardcode a hex value or font size in a screen — import from the
theme. Screenshots in design reviews should pull from these files.

## Phased roadmap (per PRD §10)

- **Phase 0 — MVP** (~10–12 wks): single team, offline-capable. Squad pitch,
  Fixtures, Live ticker, push deadline reminder. **EN only.** AR groundwork
  laid in `src/i18n/`.
- **Phase 1 — v1.0** (+8–10 wks): multi-team, multi-draft, Compare,
  Transfers (current GW), Captain (rule-based), Chips (calendar),
  Research (lineups + FDR), Arabic launch, freemium paywall, share export.
- **Phase 2 — Advanced** (+10–14 wks): multi-GW planner + solver, xPts v1,
  chip simulation, price-change predictor, template tracker, mini-league
  live, workbook, widgets, biometric.
- **Phase 3 — Future**: ML xPts, Draft FPL, tablet, in-app content,
  third-party model plug-ins.
